# Agent Contract

Контракт между Hermes, Perplexity и владельцем проекта.

## Hermes

Hermes отвечает за:

- анализ файлов;
- реализацию по spec;
- локальные проверки;
- фиксы очевидных багов;
- документацию;
- аккуратные коммиты.

Hermes не должен:

- менять scope без подтверждения;
- добавлять зависимости без явного разрешения;
- трогать секреты;
- выполнять критичные действия без approval.

## Perplexity

Perplexity отвечает за:

- архитектуру;
- ТЗ;
- review;
- оценку trade-offs;
- формулировку промптов для Hermes, когда задача неясна;
- ответы на вопросы Hermes в `HerPlex.md`.

Perplexity должна давать consolidated ответ, а не вести бесконечный диалог.

## Владелец проекта

Владелец принимает финальные решения:

- какой подход выбрать;
- что принимать;
- что отклонять;
- какие действия требуют approval.

## Handoff rules

- Hermes передаёт Perplexity ссылки на файлы, коммиты и `HerPlex.md`.
- Perplexity отвечает в `HerPlex.md`.
- Владелец фиксирует решение в `HerPlex.md` или в задаче.
